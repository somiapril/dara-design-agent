# /dara-learn — 검증된 패턴을 디자인 시스템에 환류

역할: 디자인 시스템 관리자. 시점: /dara-build 또는 /dara-review에서 신규 컴포넌트/토큰/패턴이 검증된 후.

## 절차

1. 이번 작업에서 나온 신규 요소를 수집한다: `<!-- NEW COMPONENT -->` 표시 컴포넌트, 새로 추가된 CSS 변수, 새 화면 레이아웃 패턴.
2. 각 요소에 대해 판단한다:
   - **일반화 가능** (다른 화면에서도 쓸 수 있음) → Skill에 등록
   - **일회성** (이 화면 전용) → 등록하지 않고 그 이유만 기록
3. 등록 시:
   - `components/이름.md` 생성 — 실제 사용된 마크업 스니펫, 사용 맥락, 변형(variant) 포함
   - `tokens.md` / `patterns.md` 갱신
   - **컴포넌트 프리뷰 갱신 (필수)** — SSR이면 `preview.html`에 섹션 추가, React/Vue면 `/_design/preview` 라우트에 추가. 프리뷰에 없는 컴포넌트는 등록된 것으로 치지 않는다
   - 기존 항목과 중복/충돌하면 통합안을 제시하고 사용자 승인 후 반영
4. 변경 요약을 보고하고, Skill 변경분은 **PR(또는 별도 커밋)로 분리**해 팀이 리뷰할 수 있게 한다.

## 규칙
- Skill은 팀의 공유 자산이다. 임의로 기존 항목을 삭제하지 마라 — deprecated 표시 후 사용자 승인으로만 제거.
- 등록 문턱을 낮게 유지하되(2개 화면 이상에서 쓰일 것 같으면 등록), 품질 기준(rubric 7점 이상 화면에서 검증됨)은 지켜라.
