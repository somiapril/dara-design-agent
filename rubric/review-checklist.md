# DARA 디자인 리뷰 채점 기준 (공용 rubric)

/dara-plan-review(제작 전)와 /dara-review(제작 후)가 **동일하게** 사용한다.
각 차원을 0–10점으로 채점하고, 반드시 "10점의 모습"을 서술한 뒤 개선안을 제시한다.

## 7개 채점 차원

### 1. 목적 적합성 (톤앤매너)
화면의 인상이 서비스 목적·사용자와 맞는가. 관리자 도구는 밀도와 효율, 고객 포털은 신뢰와 안내가 우선.
*10점: 화면만 봐도 누가 무엇을 하러 온 곳인지 드러난다.*

### 2. 시각 계층 (Hierarchy)
사용자의 시선이 중요한 것 → 덜 중요한 것 순으로 흐르는가. 제목/본문/보조 정보의 크기·굵기·색 대비가 단계적인가.
*10점: 3초 안에 화면의 핵심 행동 1개를 찾을 수 있다.*

### 3. 일관성 (시스템 준수)
디자인 시스템의 토큰·컴포넌트를 썼는가. 같은 의미의 요소가 같은 모습인가. 임의 색상·임의 간격이 없는가.
*10점: 이 화면의 모든 요소를 tokens.md와 components/로 설명할 수 있다.*

### 4. 밀도와 여백
정보 밀도가 사용자 과업에 맞는가. 운영 도구는 밀도 높게, 입력 폼은 여유 있게. 간격이 4/8px 그리드 등 일정 체계를 따르는가.
**카드/컨테이너 내부 여백 필수 점검**: 카드 안에 테이블·리스트·플러그인 위젯(DataTables 등)을 넣을 때 콘텐츠가 컨테이너 모서리에 붙지 않도록 기본 패딩이 있는지 확인한다 — 특히 JS가 주입하는 위젯은 패딩 없이 렌더되기 쉽다 (파일럿 QA 피드백, 2026-07-13).
*10점: 여백이 그룹핑을 대신 설명한다 — 선과 박스 없이도 구조가 보인다.*

### 5. 상태와 피드백
로딩/비어있음/에러/성공 상태가 설계되어 있는가. 버튼 hover/disabled, 폼 검증 메시지가 있는가.
*10점: 데이터가 0건일 때의 화면이 데이터가 있을 때만큼 설계되어 있다.*

### 6. 접근성·가독성
본문 대비 4.5:1 이상, 색만으로 의미 전달하지 않음, 클릭 영역 충분(44px), 폰트 크기 최소 12px 이상.
*10점: 회색조로 인쇄해도 모든 정보가 구분된다.*

### 7. AI-slop 없음 (안티 패턴)
다음이 없는가: 의미 없는 그라데이션/글로우, 목적 없는 3개 동일 카드 나열, 가짜 통계·placeholder 텍스트 잔존, 서비스와 무관한 히어로 섹션, 과도한 이모지/아이콘, 계층 없는 동일 카드 그리드.
AI 클리셰 팔레트도 감점: ① 크림 배경+고대비 세리프+테라코타 ② 검정 배경+형광 초록/주홍 ③ 신문 스타일+헤어라인+radius 0 일괄.
*10점: 모든 요소에 "왜 있는가"를 답할 수 있다.*

## 채점 규칙

- 각 차원: 점수 + 근거 2줄 + 10점의 모습 + 개선안
- **총평 금지 문구**: "전반적으로 좋습니다" — 반드시 가장 낮은 차원 2개를 지목할 것
- 7점 미만 차원은 개선안 적용 전에는 다음 단계(build/ship)로 진행하지 않기를 권고
- 제작 후 리뷰(/dara-review)에서는 계획 단계 점수와의 차이를 표로 제시
