# 화면 레이아웃 패턴

> 이 서비스에서 실제 쓰이는 화면 유형별 구조. /dara-build는 새 화면을 이 패턴 중 하나로 시작한다.

## 1. 목록 화면 (조회 + 테이블)
```
[페이지 제목 + 우측 주요 액션 버튼]
[검색/필터 영역 — 폼 요소 가로 배치]
[결과 테이블 — components/table.md]
[페이지네이션]
```
- 예시 화면: {예: /admin/jobList.jsp}
- 빈 상태: "조회 결과가 없습니다" + 필터 초기화 버튼

## 2. 상세 화면
```
[뒤로가기 + 페이지 제목 + 우측 액션(수정/삭제)]
[정보 섹션 — 레이블:값 2열 그리드]
[관련 목록/이력 테이블]
```
- 예시 화면: {…}

## 3. 등록/수정 폼
```
[페이지 제목]
[폼 섹션 — 세로 1열, 레이블 상단, 필수 표시 *]
[하단 우측: 취소(secondary) + 저장(primary)]
```
- 검증 에러: 필드 하단 red caption, 상단 요약 메시지
- 예시 화면: {…}
