# 금지 규칙 (Don't)

에이전트가 화면을 만들거나 수정할 때 다음을 절대 하지 않는다.

## 시스템 파괴 금지
- 기존 CSS 클래스명 삭제·개명 금지
- 공통 헤더/네비게이션/푸터 구조 변경 금지 (별도 승인 필요)
- 프레임워크 교체·신규 라이브러리 추가 금지 (사용자 승인 없이 CDN 추가 포함) — 단 신규(Case A) 권장 기본은 차트 **ECharts**·데이터 테이블 **Grid.js**(component-checklist 참조), 승인 후 도입. B·C는 기존 라이브러리를 따른다.
- tokens.md에 없는 색상값 하드코딩 금지

## AI-slop 금지
- 목적 없는 그라데이션, 글래스모피즘, 글로우 효과
- 동일한 카드 3개 나열로 공간 채우기
- 가짜 통계·리얼해 보이는 더미 숫자 (더미는 명확히 "예시"로 표기)
- 서비스와 무관한 히어로 이미지/일러스트
- 과도한 이모지·아이콘 장식
- 화면 전체를 동일 크기 카드 그리드로 채우기 (계층 없는 평탄한 레이아웃)
- 모든 요소에 균일한 여백 자동 배분 — 밀도는 과업 맥락에 맞게 (조회 화면은 밀도 높게, 입력 폼은 여유 있게)
- 대담한 시각 요소는 화면당 1곳까지, 나머지는 절제

## AI 클리셰 팔레트 금지 (알려진 "AI가 만든 티" 조합)
- 크림색 배경(#F4F1EA류) + 고대비 세리프 + 테라코타 강조
- 검정 배경 + 형광 초록/주홍 액센트
- 신문 스타일 레이아웃 + 헤어라인 구분선 + border-radius 0 일괄 적용

## 프로젝트 고유 금지 사항 (팀이 추가)
- {예: IE11 미지원 CSS 속성 사용 금지}
- {예: 인라인 onclick 추가 금지 — 공통 이벤트 바인딩 사용}
