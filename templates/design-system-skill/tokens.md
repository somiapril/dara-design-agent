# 디자인 토큰

> **값의 출처는 케이스에 따라 다릅니다:** 기존 코드에서 추출(B) / 기존 시스템을 따름(C) / 선택한 시안에서 도출(A).
> - **개선·수정은 허용됩니다.** 추출값이라도 개선이 필요하면 정규화·통합·조정할 수 있습니다 (예: 색상 60종 → 12토큰). 단 변경에는 근거를 남기고("원본" 열 활용), 근거 없이 임의값을 흩뿌리지는 마세요.
> - Case A는 추출이 아니라 선택 시안에서 도출하므로 기존 코드에 없던 새 컬러·타이포가 들어올 수 있습니다.

## 색상 (CSS 변수)

> 원본 파일 경로는 서비스에 맞게: 신규 레이어면 예) `/css/tokens.css`, 기존 파일 확장이면 해당 파일.

| 토큰 | 값 | 용도 | 원본 / 근거 |
|---|---|---|---|
| --color-primary | {#1a73e8} | 주요 버튼, 링크 | {.btn_blue, a.link 등에서 추출} |
| --color-primary-hover | {…} | 버튼 hover | 파생: primary 명도 −8~12% |
| --color-primary-active | {…} | 버튼 pressed | 파생: primary 명도 −16~20% |
| --color-primary-tint | {…} | 활성 배경·틴트 | 파생: primary를 화이트 88~92%와 혼합 |
| --color-danger | {#d93025} | 삭제, 에러 | |
| --color-text | {#202124} | 본문 | |
| --color-text-sub | {#5f6368} | 보조 텍스트 | |
| --color-border | {#dadce0} | 구분선, 입력 테두리 | |
| --color-bg | {#f8f9fa} | 페이지 배경 | |
| --color-surface | {#ffffff} | 카드·패널 표면 | |

> **primary 파생 규칙 (G3 — Case A · 갤러리/브랜드색 지정 시):** 사용자가 primary만 지정하면 hover/active/tint를 위 명도 스텝으로 **파생**한다. 갤러리 테마를 그대로 채택하면 테마에 정의된 hover/active 값을 그대로 옮긴다. 링크·포커스링도 primary에서 파생.

> **다크모드 지원 시**: 위 토큰은 라이트값이고, 다크값을 아래처럼 재정의한다 (색은 반드시 시맨틱 토큰으로만 사용 — 하드코딩 금지).
> ```css
> :root { --color-bg:#f8f9fa; --color-text:#202124; --color-surface:#fff; /* … */ }
> [data-theme="dark"] { --color-bg:#1a1b1e; --color-text:#e8eaed; --color-surface:#25262b; /* … */ }
> ```
> 다크모드 미지원이면 이 블록은 생략한다. (지원 여부는 인테이크에서 확정 — A·B만 질문, C는 시스템을 따름)
>
> **갤러리에서 다크 시드 (G2):** 라이트+다크 지원 시 스타일 갤러리의 **라이트/다크 짝 테마**를 함께 옮긴다 — 컬러풀은 1(라이트)↔2(다크), 톤온톤은 3(라이트)↔4(다크). 라이트값은 `:root`, 다크값은 `[data-theme="dark"]`에 넣는다. 짝이 없는 테마(5 모노)나 라이트만 고른 뒤 다크가 필요하면 표면 반전(캔버스↔잉크) + 액센트 명도 상향으로 다크 변형을 파생한다.

## 차트 팔레트 (데이터 시각화)

> 대시보드·차트가 있는 서비스만 기록한다. Case A는 갤러리 선택 테마의 팔레트를 그대로 옮기고, 서비스 데이터 특성에 맞게 조정한다(B/C는 기존 차트 색 추출/시스템 준수).

| 토큰 | 값 | 용도 |
|---|---|---|
| --chart-categorical | {색1 … 색N} | 범주형(스택 바·도넛·다계열) — 6~12색, **순서 고정** |
| --chart-tone | {램프 색1 … 색N} | 톤온톤(단일 hue 순서형·히트맵) — 톤온톤 테마 선택 시 |
| --chart-grid | {…} | 축·그리드 라인 (hairline과 동계열) |
| --chart-axis-text | {…} | 축 레이블 텍스트 (text-sub와 동계열) |
| --chart-surface | {…} | 차트 배경 (카드 표면과 일치) |

- 범주형은 **인접색 대비**를 확보하고(색각이상 고려), 세그먼트 사이 1~2px 서피스 갭 + 범례로 저대비를 보완한다.
- **다크 지원 시 차트 팔레트도 라이트/다크 2벌**(다크는 명도 상향). 갤러리 짝 테마의 A(톤온톤)/B(멀티컬러) 팔레트를 그대로 활용.
- 시맨틱(성공·경고·에러)은 위 **색상 토큰**을 쓴다. 톤온톤 테마라도 시맨틱은 기능색을 유지한다.
- **렌더 라이브러리 기본**(신규/Case A): 차트 = **ECharts**, 데이터 테이블 = **Grid.js**(경량·정렬). 위 색 토큰으로 통일. 상세·예외는 component-checklist "렌더 라이브러리 기본값" 참조.

## 타이포그래피

- **폰트: 정해진 게 없으면 Pretendard를 기본으로 지정한다** (`--font-family: "Pretendard Variable", "Pretendard", -apple-system, sans-serif`). 기존 시스템/브랜드 폰트가 있으면 그것을 우선.
- weight: 본문 400 / 레이블 500 / 소제목 600 / 제목 700. `bold` 키워드 대신 숫자로 통일.

**밀도 프리셋 — 화면 성격에 맞게 하나를 고른다:**

| 토큰 | Comfortable (홈·랜딩·마케팅) | Compact (대시보드·콘솔·데이터 밀집) | 용도 |
|---|---|---|---|
| --font-hero | 40~60px / 700 | (미사용) | 히어로 타이틀 |
| --font-title | 22~24px / 700 | 18~19px / 700 | 화면·섹션 제목 |
| --font-subtitle | 17~18px / 600 | 14~15px / 600 | 소제목·카드 제목 |
| --font-body | 15~16px / 400 | 13~14px / 400 | 본문·테이블 |
| --font-caption | 13px / 400 | 12px / 400 | 보조 설명 |
| line-height | 1.5~1.6 | 1.4~1.5 | |
| letter-spacing | -0.01em (제목 -0.02em) | -0.01em | |

> 판단 기준: 정보 밀도가 낮고 "읽는" 화면(홈·소개·랜딩)은 **Comfortable**, 한 화면에 많은 데이터를 "훑는" 화면(대시보드·콘솔·목록/조회)은 **Compact**. 한 서비스 안에서도 화면 유형별로 다르게 쓸 수 있으니, 시스템에는 두 세트를 모두 기록하고 화면마다 선택한다.

## 간격 (4px/8px 그리드) — 밀도 프리셋

| 토큰 | Comfortable | Compact | 용도 |
|---|---|---|---|
| --space-1 | 4px | 4px | 아이콘-텍스트 사이 |
| --space-2 | 8px | 8px | 요소 내부 패딩(소) |
| --space-3 | 16px | 12px | 요소 간 간격 |
| --space-4 | 24px | 16px | 카드 내부 패딩 |
| --space-5 | 40px | 24px | 블록 간 간격 |
| --space-section | 64~80px | 32~40px | 섹션 간 간격 |
| 카드 gap | 16~20px | 12px | 그리드 간격 |

> Comfortable은 여백으로 그룹을 나누고(넓은 섹션 리듬), Compact는 밀도를 높여 한눈에 더 많은 정보를 담는다. 예: 홈·랜딩 = Comfortable, 대시보드·콘솔·데이터 조회 = Compact.

## 기타

**border-radius 스케일 (G5)** — 갤러리 선택 테마의 라디우스 셋을 그대로 옮긴다(테마마다 다름: 예 모노 버튼6/카드8, 톤온톤 버튼6/카드10+pill 뱃지):

| 토큰 | 값 | 용도 |
|---|---|---|
| --radius-sm | {6px} | 버튼·인풋·뱃지 |
| --radius-md | {8~10px} | 카드·패널·차트박스 |
| --radius-pill | {999px} | pill 뱃지·CTA (해당 테마만) |

> 단일 라디우스로 통일하는 시스템이면 --radius-md 하나만 두고 나머지는 생략 가능.

- box-shadow: {0 1px 3px rgba(0,0,0,.12) — 카드/모달만}
